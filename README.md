# 김진현 — Character & Game Art

캐릭터, 게임 소품, 수채화풍 게임 UI를 소개하는 정적 포트폴리오입니다.

## 구성
- `index.html`: 작품 목록과 소개
- `style.css`: 데스크톱·모바일 레이아웃
- `script.js`: 작품 필터와 키보드로 이용 가능한 상세 보기
- `images/`: 기존 작품 원본 (변경 없음)
- `assets/watercolor/`: 수채화 UI 원본 2개 및 포트폴리오 미리보기
- `downloads/Watercolor_Fantasy_Portfolio.zip`: 원본·미리보기·README·파일목록·alpha 검사 결과

빌드나 외부 서비스 없이 GitHub Pages에서 제공됩니다. 저장소 경로 아래에서도 동작하도록 상대 경로를 사용합니다.

## 자료 범위
수채화 UI는 ChatGPT로 생성·수정한 작업이며, 접근 가능한 PNG 두 파일만 포함했습니다. 두 파일 모두 아이템이 남아 있는 텍스트 없는 UI입니다. 캐릭터(농부 아버지), 마법학교, 과거 건물 시트, 빈 인벤토리 버전은 파일을 확보하지 못해 포함하지 않았습니다. 자세한 검사는 ZIP 안의 문서를 참고하세요.

기존 저장소의 실제 캐릭터·소품 이미지 3개는 그대로 보존했습니다. 파일이 없는 예시 작품과 임시 영상은 공개 목록에서 제외했습니다. 저작물 이용 허가는 별도 문의해 주세요.
